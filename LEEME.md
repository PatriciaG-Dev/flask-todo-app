# Proyecto: Mini To-Do App con Flask

## Descripción
Aplicación web que permite agregar tareas y visualizarlas en una lista.

## Funciones que realiza
- Crea un servidor web local
- Muestra una página HTML
- Permite enviar datos desde un formulario
- Guarda tareas en memoria
- Redirecciona rutas

## Librerías necesarias
Flask

## Cómo ejecutarlo
1. pip install -r requirements.txt
2. python app.py
3. Abrir http://127.0.0.1:5000
